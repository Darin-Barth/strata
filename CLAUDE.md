# Strata — "Build. Fly. Explore."

Kitchen-sink Minecraft modpack (500–600 mods) for 5–6 friends. Managed with **packwiz** in this repo.
Source of truth: `docs/design-doc.md` (rules) and `docs/strata-mod-tracker.xlsx` (mod list, sheet `Mods`).

## Hard constraints
- **Minecraft 1.21.1, NeoForge only.** Create Aeronautics forces this. Never add a Forge/Fabric-only or other-version file.
- Only add mods whose tracker Status is **Keep**. Maybe = undecided (ask), Cut = never add.
- Verify builds via the Modrinth/CurseForge APIs (or packwiz), never from memory.
- Prefer Modrinth; fall back to CurseForge. Set `side` (client/server/both) to match the tracker.
- Hosting: treehouse server, itzg/minecraft-server Docker image. Server-side choices must work headless.

## Pillars
1. Tech/automation (Create + add-ons, Mekanism, AE2, IE, etc.) 2. Magic (Ars Nouveau hub + bridges) 3. Exploration/bosses/dungeons.
Test for any mod: keep if it adds a different way to play; question it if it duplicates something already in.

## Rules to enforce while building
- **Limited teleport**: one `/home` per player with a 10-second cooldown (`kubejs/server_scripts/strata_home.js`, Darin's call Oct 25); no `/back`, `/rtp`, `/tpa` for non-ops (no FTB Essentials). Waystones only with distance-scaled XP cost + extra cross-dimension cost; remove Waystones' warp scrolls/stones from loot. Ars' single-use Warp Scroll stays; its reusable cross-dimension Stabilized Warp Scroll costs 2 echo shards (gate M21). Earned teleporting (Mek teleporters, Ars, blink spells, Vampirism skill, Iron's Portal spell, Oritech portal augment) is fine. Removed (Darin, Oct 26): Iron's Recall spell, all Draconic dislocators, Helium Flamingo, Wind Staff and Forsaken Relics' Linking Book (`server_scripts/strata_removed_items.js`). Corail Tombstone (Oct 27): its teleport tablets are off in `config/tombstone-server.toml` and its teleport commands are ops-only (`server_scripts/strata_tombstone.js`); the Grave's Key teleport to your grave stays (Darin). MineColonies: allied Town Hall teleport off.
- **No easy "creative" flight**: flight is fine when it takes real effort to get (boss materials, late-game tiers, taming a dragon) or has an ongoing cost (fuel, power, mana, XP, food for pets, stamina). Reviewed Oct 25 (Darin relaxed the rule after friends' feedback): every current flight source passes, e.g. Angel Ring needs Grid Power, Inventory Pets' Flying Saddle and Cloud pets must be fed, Excelsius chestplate needs Cataclysm boss materials. Gate only something cheap AND free to run.
- **Wireless**: no tiers enforced (Darin, Oct 25). Flux Networks, Mekanism entangloporters and Mighty Mail work across dimensions as the mods ship them; AE2's Quantum Network Bridge keeps its own recipe cost.
- **Power**: Crafts & Additions alternator (FE output lowered) < New Age generators < New Age nuclear / Mek fission+fusion. New Age's Electrical Connector is removed (`server_scripts/strata_power.js`; its generators feed C&A/IE through carbon brushes); grid = C&A wires (local) + IE LV/MV/HV (long distance). C&A alternator 240 FE at max RPM.
- **Difficulty**: no server-wide stages (Darin, Oct 26: players progress at very different paces, so the Nether/Dragon steps and the planned staged-difficulty script are dropped). Difficulty stays per player: Apotheosis World Tiers (each player chooses), dimension danger (the Hollow), bosses with designed stats. Apotheosis elites rare near spawn. Vampirism scales its own mobs.
- **Ores by dimension**: `docs/ore-map.md`, generated by `tools/build_ores.py` (Mekanism's `config/Mekanism/world.toml` plus datapack overrides; re-run after a mod update). Starting metals stay at home (thin where a dimension has the rich veins); duplicate ores generate from the Almost Unified target only. Applies to newly generated land only.
- **Boss gating**: `docs/gate-map.md` (approved and built Oct 26): tech, magic and gear tiers need boss drops, Hollow Embers or Abyssal Pearls; generated by `tools/gates/build_*.py` into `kubejs/data` (re-run after a mod update). Magic gets more and earlier road blocks than tech (Darin). Wireless is never gated.
- **End portal eyes**: `docs/end-eyes.md` (Darin, Oct 29): every eye has one guaranteed source (bosses, one treasure chest type, a Create or Ars craft), never a random drop; 3 spare eyes so nobody is forced through every boss; Seeker's Compasses are the paid way to find the places (Explorer's Compass can't). Generated by `tools/build_end_eyes.py`.
- **Combat**: Better Combat + Apothic Combat + Combat Roll. Not Epic Fight.
- **Magic bridges**: Ars 'n Spells + Iron & Nouveau (never also Ars↔Iron Mana Bridge), Ars Ocultas, Ars Énergistique, Ars Creo, Apotheosis×Iron's, Vampirism×Iron's.
- **Worldgen**: Tectonic + Regions Unexplored + Streams Reflowing. No Terralith, no Dynamic Trees, no C2ME. Incendium (not with Amplified Nether), Nullscape. Pregenerate with Chunky.
- **Client/visual**: every heavy visual is client-only and optional, except Distant Horizons, which also runs on the server (Oct 29) to stream LODs of existing land; `startup_scripts/strata_dh_chunky.js` stops DH 3.3.3 + Chunky crashing the server boot, and DH is off in the Hollow and the Abyssal Plain (it ignores their fog). Sodium (not Embeddium) + Iris. EMI is the only recipe viewer (EMI Ores, Advanced Loot Info and Just Enough Breeding cover what JER did). JEI and JER were removed Oct 25: JEI builds its recipe index on the client's main thread when joining (about 60 s with this pack), which timed players out. Botania and Ars Botania are out (no 1.21.1 build). Curios is the accessory standard (Accessories only if a mod needs it).
- **Pokémon**: Cobblemon in its own dimension, shown to players as **the Kakuto Region** (IDs stay `pokeworld:*`; datapack, own namespace); wild spawns disabled elsewhere; riding allowed everywhere. Built after the base pack is stable.
- **Horror: The Hollow** (`strata:hollow`, `docs/hollow-design.md`): every horror mob mod is confined there (biome tags under `strata:`, never `is_overworld`, plus the In Control! deny rule). Scary but fair: no one-shots (40% damage cap), every threat has a warning and a counter. Generated by `tools/build_hollow.py`; re-run after a horror-mod update.
- **Underwater: The Abyssal Plain** (`strata:abyssal_plain`, `docs/abyssal-plain-design.md`): no surface; generated by `tools/build_abyssal_plain.py`. Keep the column above Y -54 (hard-coded lava) and never use heightmap-based placement there (the ceiling is the heightmap).

## Working notes
- KubeJS (Rhino) scripts: never `const` inside a loop body, try/catch or a top-level block (Rhino reuses the first value or throws); use `let`. Run `python -I tools/check_kubejs_const.py` before committing scripts. Some Java names differ through KubeJS wrappers: DamageSource attacker is `.actual` (no getEntity()), a level's dimension is the property `level.dimension` (an ID), `entity.type` is the ID string, damage an entity with `entity.attack(source, amount)` (hurt() is hidden), a player's tick counter is `player.tickCount` (`player.age` is undefined, so `age % n` checks silently never run); probe on the test server when unsure. Client-only code paths aren't exercised by server boots: test them with the guard forced on.
- packwiz: `packwiz refresh` after manual edits; `packwiz mr add <slug>` / `packwiz cf add <slug>`. Modrinth mods also carry an `[update.curseforge]` section for the CurseForge export: run `python -I tools/curseforge_ids.py` after adding or updating mods (never hand-edit those sections; separate per-site builds go in `tools/curseforge-manual.json`).
- Balance patch (`docs/balance-patch.md`): recipe changes are generated by `tools/build_balance.py` (re-run after a Theurgy or Bountiful update), scripts in `strata_balance.js`, the rest in `config/`. Relics runs with extended configs on (`config/relics.yaml`): its per-relic files in `config/relics/relics/` don't update with the mod, so re-check them after a Relics update.
- Lookup script and results: `tools/` (results in `tools/lookup-results.json`).
- `config/royalvariations.toml` ships byte-for-byte as the game writes it (no comments, no edits): Royal Variations holds the file open while NeoForge rewrites a config it finds "not correct", and on Windows that write fails and a fresh install crashes on its first launch ("Failed to wait for future Config loading", Oct 27). Regenerate it from a client after a Royal Variations update. NeoForge rewrites any shipped config whose comments differ from the mod's own, so comments in other configs are fine but get stripped on players' machines.
- Keybinds: the default layout is `config/defaultoptions/keybindings.txt` (new installs only), documented in `docs/keybinds.md`. Never put a Ctrl+key bind on a key pressed while sprinting (E, T, R, B, M, Q, F, 1-9): sprint holds Ctrl, so the combo fires instead of the plain key. Effortless Building ignores an Alt modifier on its keys.
- Configs in `config/` ship with the pack. Pack-balance configs (Quark, ModernFix) are enforced. Per-player comfort/performance configs (Distant Horizons, Camera Overhaul) get `preserve = true` in `index.toml` so updates don't overwrite players' own settings (`packwiz refresh` keeps the flag).
