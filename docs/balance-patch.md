# Balance patch

Status: **built** (shipped in 1.0).

Recipe count changes are generated by `tools/build_balance.py` (re-run after a Theurgy or Bountiful
update). Changes that need a script are in `kubejs/server_scripts/strata_balance.js` and
`kubejs/startup_scripts/strata_boss_blast_cap.js`. The rest ships in `config/`.

The rows come from audits of the mods' own recipes, loot and configs on the test server
(tech, magic, gear/bosses, everyday/QoL). Each row states the problem and the rule now in place.

## A. Boss drops can't be farmed

Every gate ingredient (ignitium, lava power cell, void core, naga scale, lich trophy, Embers,
Pearls...) must stay a boss or dimension drop. The entity tag `strata:unfarmable` blocks bosses and
the mini-bosses that drop gate items from every capture and duplication route. Normal mobs stay
farmable.

| # | Route | Rule |
|---|---|---|
| A1 | Mob Grinding Utils **Mob Swab** turns a mob into a spawn egg for its Entity Spawner + Saw (Cataclysm and Twilight bosses have eggs) | bosses can't be swabbed or spawned (`strata:unfarmable`) |
| A2 | Ars Nouveau **Containment Jar** + **Drygmy** "produce items from nearby monsters as if slain" | jars and Drygmys can't take bosses |
| A3 | Occultism soul gem + Dimensional Battlefield on mini-bosses outside `#c:bosses`: Ender Golem (void core, T6), Baby Leviathan (abyssal egg, T10), Void Worm (M7) | soul gems can't take them |
| A4 | Industrial Foregoing Mob Duplicator and imprisonment tool, Oritech spawner | blocked for bosses |
