# Queued for the next update

Changes committed on master since the last release (**v1.5.0**; notes in the GitHub release) that haven't been released yet. Policy: changes ship together in one update (merge to `master` + new `.mrpack` release + server restart); only a critical hotfix goes out on its own. Queued work can be backed up to the GitHub branch `next-update` (`git push origin master:refs/heads/next-update`); the server only follows `master`.

## Changes
- **Dragons no longer damage terrain or builds (Darin, Nov 20):** Ice and Fire's `griefing`, `tamedGriefing`, `digWhenStuck` and `destroyBoats` are off for dragons (`config/iceandfire/iaf-common.json`). Cyclops and sea serpent `griefing` are off too.
- **Fewer vampires, and their bite rarely infects (Darin, Nov 20, Strata Tweaks 1.3.0, server-side):** vampires spawn under Vampirism's own cap (30 per player area, on top of the hostile cap); a count on the running server found 47 vampires and 29 hunters against about 100 of every other hostile. The cap is now scaled to 12 (`vampireCapScale = 0.4`). A vampire mob's bite infected every time it drank from a player who wasn't looking at it (the mod has no setting); it now infects 15% of the time (`vampireBiteInfectChance`). Both in `config/strata_tweaks-common.toml`. Hunters (own cap of 15) and Werewolves (bite infects 5%) are unchanged.
- **Fewer anglerfish (Darin, Nov 20):** Naturalist's anglerfish spawn in every ocean with no weight setting; an In Control rule now stops new ones once there are two per player in the dimension (`config/incontrol/spawn.json`; the Abyssal Plain keeps its own limit of four).
- **New item: the Omnistrata (Darin, Nov 19, Strata Tweaks 1.3.0, needs the client update):** one hotbar slot that holds six tools (pickaxes, axes, shovels, hoes, shears, wrenches, building wands and gadgets; no weapons). Hold V for a wheel and let go over a tool, tap V for the last tool, scroll to step through, let go in the middle to put it away. Put it away and right-click with it in hand to open its six slots and add or remove tools. The tool in hand is the real tool (enchantments, durability, wrench behaviour all its own). Recipe: iron, copper, iron / iron, wooden chest, iron / iron, gold, iron (ingots). The icon is a steel tool case.
- **New mods: Create Encased 1.10.1-fix1 and Create: Vibrant Vaults 0.3.2 (Darin, Nov 18):** casings for shafts, cogwheels and pipes, and coloured vaults, frogports, stock links and packagers. Tested together on a test server and client: no change in boot time, tick time (512 of each block next to a player) or client load time. Bits 'n' Bobs' compatibility patch for Encased doesn't find its target in this Encased version (a warning only); it may hide some Encased wooden cogwheels from the recipe viewers. Looked at and not added: Design n' Decor (overlaps Create Deco, 256 log errors a start), Ars Technica (Thread of Pressure, Source Motor and Focus of Transmutation would need gating first), Protection Pixel (MCreator, ability armour outside the gear gates), Create Better FPS (client-only, shaders only, hides Steam 'n' Rails phantom rails).
- **Repair Talisman no longer feeds Inventory Pets (Darin, Nov 17, Strata Tweaks 1.2.2, server-side):** the talisman repaired the pets' durability bar, which is their hunger, so pets never needed food. It still repairs tools and armour. Tested on a test server (pickaxe and chestplate repaired, two pets untouched).
- **Accessories are rarer in loot chests (Darin, Nov 17):** measured on a test server, Forsaken Relics put one of its relics in 11-12% of every chest in the game (a fixed 12% in its code), and Relics adds one to 20% of the chests a player opens (`relicGenChance`); together about one chest in three. Now Forsaken Relics rolls a quarter as often (`kubejs/data/forsaken_relics/loot_modifiers/relic_chests.json`, measured 3%) and Relics is at 5% (`config/relics/loot.yaml`), about one chest in twelve. Artifacts was left alone (none in 300 rolls of each of six chest types). Chests already opened keep what they had. Still to check: that Relics reads the 5% (it only rolls when a player opens a chest), and whether one in twelve feels right in play.
- **Other players' waystones no longer appear on your map (Nov 17, Strata Tweaks 1.2.2, server-side):** the mod that turns waystones into Xaero waypoints sent one to every player online whenever any waystone was renamed or edited, so everyone collected everyone else's waystones (in the wrong dimension too), and a deleted one came back at the next edit. A waypoint now only goes to a player who has activated that waystone and is in its dimension. Waypoints already on a map stay until deleted (Waypoints list, `U` by default). Checked by a test server boot; still to check with two players: rename a waystone and confirm only players who activated it get the waypoint.
- **Server crash at the end of a gym battle (Nov 17, hotfix):** Integrated Cobblemon 1.2.1 writes all 1,449 lines of its 69 gym trainers as plain strings; Radical Cobblemon Trainers' speech bubbles need a translation key and throw on them (`TrainerMob.addMessage(null)`). When that happens as a battle ends, Cobblemon catches the error and force-stops a battle that is already over, which throws again and stops the server (`sendBattleMessage: Cannot read property 'write' of undefined`, crash of 17:47). Trainer lines are now shown in chat instead of speech bubbles (`config/rctmod-server.toml`: `showMessagesAsSpeechBubble = false`, `showMessagesInChat = true`; takes effect without a restart). Reproduced and checked on a test server with the Bug Gym's first trainer: all three lines threw before and are said after. **Still to do:** make Strata Tweaks keep the bubbles working for plain-text lines and stop Cobblemon's failed force-stop from ever reaching the server tick.
- **The End is sealed until its portal is opened with twelve eyes (Darin, Nov 17; tested on a test server):** an audit found four ways into the End that skip the eyes (a Weeping Angels catacomb room with a working portal, Oritech's particle accelerator, AE2 Spatial IO moving pre-filled frames, an Integrated Dynamics teleport packet). Each is closed, and behind them a rule: nobody can enter the End by any means until someone has crossed a portal ringed by twelve End Remastered frames with eyes. Details and the test in `docs/end-eyes.md`. Server-side: players on the 1.5.0 pack can join without updating (Strata Tweaks 1.2.1 on the server, 1.2.0 on clients, tested).
- **Sunken Spires' guardians have their real stats on the server (Nov 17, server-only, already live):** four of its structures were saved in Minecraft 1.21.4 and 1.21.1 dropped their attribute names, so the Colosseum guardian had 20 health instead of 180, no size, plain gear. Corrected copies are in the server's structure datapack (`tools/structure-templates/fix_attributes.py`); the Abyssal Plain was regenerated after it. **Still to do for single player and for any other such mod:** make Strata Tweaks accept the newer attribute names (registry aliases), then the corrected copies can go.

## Watch
- **Tried and dropped, a per-tick budget for fluid settling in new chunks (Nov 15):** settling water and lava in freshly generated chunks was 16.5% of the main thread in the Nov 15 live profile, so a Strata Tweaks build queued those positions and settled a few milliseconds' worth per tick. It worked (all positions settled, none lost) but changed nothing measurable: with the same seed, the same 12 hops and a real client, 37.1 s behind in total (worst 6.9 s) without it and 38.4 s (worst 7.2 s) with it, about 600,000 fluid positions either way. The work is only moved, not removed, and it is not what the stalls are made of. Not shipped. Also learned: Chunky generating with nobody online triggers almost none of that fluid work (500-3,500 positions per 2,600 chunks); it appears around players.
- **Spark's background profiler and Macs (Nov 15, a lead):** a test server on an Apple Silicon Mac crashed twice during start-up in spark's native async-profiler library (`ThreadFilter::accept`, SIGSEGV) and started fine with `backgroundProfiler` off (`config/spark/config.json`). The Nov 14 Mac client crashes were also native JVM crashes while loading. If a Mac player keeps crashing on launch, try turning spark's background profiler off on that install before anything else.
- **C2ME can't run on the live server (Nov 15):** tried as a server-only mod (0.4.0-alpha.0.124) to cut the stalls while players explore new land; removed again the same day. On the live server the main thread stopped two minutes after starting. Reproduced three times on a test server with a copy of the live world (12 GB): the main thread waits forever on a chunk load that Hyperbox asks for during the tick while C2ME's workers keep reading chunks from disk, and the heap fills within about a minute (OutOfMemoryError). A Strata Tweaks patch that made Hyperbox's force-load non-blocking (`Hyperbox.onPreLevelTick` -> `setChunkForced`) only moved the wait to Hyperbox's next call (`onPostLevelTick` -> `shouldUnloadDimension` -> `getBlockEntity` -> `getChunk`), so it was dropped. Not established: whether Hyperbox is the only trigger, and whether Distant Horizons on the server plays a part. C2ME stays a pregen-only tool, on a server copy.
- **Server crash at 21:43 on Nov 6** (entity tracking map changed mid-tick, `ChunkMap.tick`): not explained by the Cloudy Temple fix in 1.4.0. If it happens again, keep the crash report.

## Release checklist
1. Check `version` in `pack.toml` and the version line in `config/fancymenu/customization/strata_title_screen.txt` (both the new version).
2. `python -I tools/curseforge_ids.py` (re-adds CurseForge IDs after mod updates; fix any "no longer used" line in
   `tools/curseforge-manual.json`), `packwiz refresh`, commit, `git push` (master, and sync `next-update`). Check no stray files sit under the server's `kubejs/data`: KubeJS refuses to start on an uppercase file name there.
3. `packwiz mr export -o build/Strata-<version>.mrpack`; `gh release create v<version>` with the notes below.
   The CurseForge Action (`.github/workflows/curseforge.yml`) then builds `Strata-<version>-curseforge.zip`, attaches
   it to the release and, when the repo variable `CURSEFORGE_UPLOAD` is `true`, uploads it to CurseForge with the
   release notes as the changelog (CurseForge reviews it before it goes public). One-time setup by the repo owner: secret
   `CURSEFORGE_TOKEN`, variables `CURSEFORGE_PROJECT_ID` and `CURSEFORGE_UPLOAD`; leave the upload off until
   Drive-By-Wire is on CurseForge's approved list (requested), or CurseForge rejects the file. To upload a
   release that's already out: Actions → CurseForge → Run workflow with its tag.
4. If `python -I tools/structure-templates/datapack.py check <datapack> <mods dir>` reports anything (or the datapack isn't on the server yet), regenerate it and copy it to the server's `world/datapacks/strata_templates` before restarting. On the server, add `JVM_OPTS: "-Dneoforge.readTimeout=120"` under `environment:` in `/opt/minecraft/strata/compose.yml` (back it up first); a compose change needs `docker compose up -d`, not just a restart. After any `up -d`, check `docker exec strata cat /proc/sys/net/ipv4/tcp_congestion_control` prints `bbr` (the compose `sysctls`, Nov 8). Wait about 5 minutes for GitHub's raw-file cache, then restart the server (Quarry restart, or `docker compose restart`
   in `/opt/minecraft/strata`). Check the log for `Loaded N/N KubeJS server scripts ... 0 errors`.
5. Tell the group to import the new `.mrpack`.

Note: `config/DistantHorizons.toml` and `config/cameraoverhaul.toml` are `preserve = true`, so players who already have
them keep their own copy. Changes there only reach new installs.
