# Queued for the next update

Changes committed on master since the last release (**v0.4.3**; notes in the GitHub release) that haven't been released yet. This release will be **v0.5.0** (version already set in `pack.toml` and the title screen). Policy: changes ship together in one update (merge to `master` + new `.mrpack` release + server restart); only a critical hotfix goes out on its own. Queued work can be backed up to the GitHub branch `next-update` (`git push origin master:refs/heads/next-update`); the server only follows `master`.

## Changes
- **Less memory:** Every Compat no longer makes Chipped, Rechiseled, Macaw's Furniture and Handcrafted copies in modded woods (23,002 fewer blocks; 872 MB less on the server, likely 1-1.5 GB less in your game). It also drops its Quark (posts, ladders, chests...) and Another Furniture copies in modded woods: 760k fewer block states, so a lighter, faster-loading game. Quark's and Another Furniture's own blocks stay. Those blocks disappear if anyone placed them. Distant Horizons default view distance 64 chunks for new installs.
- **Rhino** 2101.2.7-build.85 → 2101.2.8-build.91 (the build CurseForge also hosts; KubeJS needs ≥ build.81; test server: 7/7 startup and 14/14 server scripts, 0 errors).
- **CurseForge export (for the pack's maintainers):** every Modrinth mod now also carries its CurseForge file ID (`tools/curseforge_ids.py`), so `packwiz cf export` builds a CurseForge zip next to the `.mrpack`. A GitHub Action builds that zip for every GitHub release, attaches it, and can upload it to CurseForge. Nothing changes for players or the server.
- **CobbleStructures and Sunken Spires are server-only** (data only: structures and loot, no client files). Nothing changes on the server; players' downloads drop two files. Single-player worlds from the client pack won't get those structures.
- **Serene Seasons 10.1.0.9 → 10.1.0.3**: the newest 1.21.1 build on CurseForge, so both versions of the pack match. Test server: boots clean, seasons change normally. **Watch for:** a crash with `StackOverflowError` mentioning `sereneseasons` / `MixinBiomeClient` / `hasPrecipitation` (fixed in 10.1.0.9, #613). If it shows up, go back to 10.1.0.9 on Modrinth.
- **Inventory Pets are found, not crafted**: pet recipes and the Petrifier are gone. Pets now turn up in structure chests: cozy pets in dungeons, mineshafts and temples; handy ones (Anvil, Furnace, Pingot, Juggernaut...) in strongholds, mansions and fortresses; the legendary six (Black Hole, Slime, Wither, Sun, Cloud, Pufferfish) only in End cities, ancient cities, bastion treasure and ominous trial vaults. Strong pets are weaker: Juggernaut and Illuminati cooldowns are 10 minutes, Pac-Man's damage boost builds slower, the Pingot finds ore but doesn't dig it out, and several strong pets eat costlier food (diamond, emerald, ender or netherite nuggets, golden carrots, iron ingots). The Nether Portal pet only works once you've been to the Nether yourself. Pets you already have keep working. (Boot-tested: scripts load and the pet loot tables roll; the Nether Portal check still needs someone to try it in game.)
- **MineColonies**: build and run a colony of NPC workers. Adds Structurize, Domum Ornamentum, BlockUI, Multi-Piston and TownTalk (colonist voices), all pinned to the tested versions. Cost measured on the test server and a test client: +94 MB server memory, +7-9 s server start, about +2 s game load, +133 MB download. Teleporting to allied Town Halls is off (limited-teleport rule); MineColonies' `/mc rtp`, colony and home teleports are off by default. Colonies get raided every 10-14 nights once founded. Not measured: server load from a busy colony. No quest chapter yet.
- **Corail Tombstone replaces GraveStone Mod**: your items wait in a grave where you died, and you respawn with a Grave's Key that teleports you to the grave. Its other teleports are off: the Tablets of Home, Recall, Assistance and Cupidity and the Lost Tablet are disabled, and `/tbrequestteleport`, `/tbacceptteleport` and `/tbteleportdeath` are ops-only. **Before updating, everyone should empty any GraveStone graves: they disappear with the old mod, items included.** Test server: boots clean, 17/17 server scripts, tablets off in the config. Not tested in game: a real death and the command block for a non-op player.
- **Skill trees reworked** (Ctrl+K; `docs/skill-trees-rework.md`): fewer, bigger nodes and keystones that change how you play. Combat has four branches (Warrior: life steal; Ranger: arrow speed and armor pierce; Guardian: dodge; Duelist: crits) and 25 levels for a 33-point tree, so you choose. Mining XP now comes from every ore in the pack, not only vanilla ones, with whole Fortune levels, a shovel/axe keystone and an experience branch. Fishing values doubled, new Sea Legs keystone. Iron's magic trees need a third of the XP, nodes are twice as strong (the first tree has 25 levels instead of 50) and the gateway nodes give -10% cooldowns or +10% spell power. Points you already spent may be reset by the change.
- **Balance patch, part 1** (`docs/balance-patch.md`): bosses can't be turned into spawn eggs (Mob Grinding Utils); the Oritech fission reactor needs an ignitium ingot like the other reactors; Theurgy gives 3 ingots per ore instead of 5 and no longer turns iron/gold into desh/ostrum; Excessive Utilities quarries cost more energy and the Ender Quarry is limited to a 1,024-block fence; Mekanism Refined Obsidian gear is netherite-level; Ice and Fire dragonsteel does 14 damage instead of 25; no omega stack upgrades; Simply Swords uniques are rarer; the Charm of Sinking doesn't work in the Abyssal Plain; the cheat-death relics have longer cooldowns (the Seven Sins ring's standing-still immortality is gone, the Leafy Mantle is no longer in loot); Bountiful's netherite, diamond, Mending and totem rewards are rarer; Carry On can't move spawners (use a Mekanism cardboard box); everyone starts with 10 Numismatics cogs; epic quest bags give 1 netherite ingot.
- **Balance patch, part 2**: bosses and gate-dropping mini-bosses can't be jarred (Ars), soul-gemmed (Occultism), duplicated (Industrial Foregoing) or spawned (Oritech); normal mobs still can. Powah reactors make far less power (basic 240 FE/t like an alternator, spirited 6,000, nitro 15,000 instead of 500,000), so the boss-gated reactors stay the top power. The Rainbow Generator makes 250,000 FE/t instead of 25 million. Create Enchantment Industry's Affix Augmentor needs a Hollow Ember, and its Gem Cutter no longer makes flawless or perfect gems (use Apotheosis' table). Explosions and Big Cannons shots do at most 10 damage per hit to Bosses of Mass Destruction and Bosses'Rise bosses. Ars Nouveau's Stabilized Warp Scroll (reusable, works across dimensions) now needs 2 echo shards from ancient cities; the single-use Warp Scroll is unchanged, and stabilized scrolls already made keep working.
- **Boss loot bags:** boss fights are group events now. When a boss dies, nothing drops on the floor: everyone who hit it in the last 10 minutes gets their own **Boss Loot Bag** with a full share of its loot (right-click to open). No more splitting one drop or refighting a boss so everyone gets a turn. Twilight Forest bosses still fill their own treasure chest for the player who lands the killing blow.
- **Legendary pets from bosses:** the Cloud pet can drop from the Sun Spirit, the Sun pet from Ignis, the Wither pet from the Harbinger, the Black Hole pet from the Ender Guardian and the Pufferfish pet from Scylla or the Leviathan (15% each, rolled for every player in the fight). Legendary pets are rarer in chests (2.5%). The Nether Portal pet is now found only in Nether fortresses and bastions. The Slime pet stays a chest find.
- **Fix: a fresh install could crash on its very first launch** (worked from the second launch on). NeoForge has to rewrite `royalvariations.toml` on the first run, Royal Variations holds that file open, and Windows refuses the write; with 12-16 GB of memory the game loads fast enough to hit it nearly every time. The pack now ships that file complete (and Weeping Angels' spawn config up to date), so nothing needs rewriting. Test: 3/3 fresh installs failed at 16 GB before, 4/4 start cleanly after.
- **Fix: the Abyssal Plain, the Hollow and the Charm of Sinking rule weren't running.** Their every-second checks read a player property that doesn't exist in this KubeJS version, so they silently did nothing: arriving in the Abyssal Plain didn't build your Lifepod, Conduit Power wasn't cleared there, the Hollow never started its scare events or its arrival grace period, and the Charm of Sinking kept working in the Plain. All four now work (test server with a client: Lifepod deployed on arrival, charm comes off, Hollow arrival recorded).
- **Fix: Kakuto's Fire Gym chests were empty**: Integrated Cobblemon's Fire Gym loot table asks for a "spiky bomb" that Supplementaries doesn't have on 1.21.1, so the whole table failed to load. Strata ships a copy with the normal bomb.
- **Quest book matches the current rules**: difficulty is per player (World Tiers), wireless has no Nether requirement, and one `/home` per player is mentioned; the 256k AE2 cells point at the Ender Guardian's Void Core; the World Tier quests name the Hollow Ember (Summit) and Abyssal Pearl (Pinnacle). The joining guide is updated the same way.

**Tested (test server + client):** Corail Tombstone: a non-op can't use `/tbrequestteleport`, `/tbacceptteleport`, `/tbteleportdeath` or `/tbteleport` (ops can); `/sethome` and `/home` work; on death you bleed out (PlayerRevive), then your items go into a grave and you respawn with a Grave's Key to it. MineColonies: a colony with 66 citizens raised the Overworld tick time by about 3.5 ms (from ~20 to ~23.5 ms of the 50 ms budget, still 20 TPS); idle citizens, so a colony full of busy workers costs more.

**Check while playing (tested in normal play after release):** the Nether Portal pet refuses before your first Nether visit and works after; bosses can't be jarred (Ars) or soul-gemmed (Occultism); explosions and Big Cannons shots do at most 10 per hit to Bosses of Mass Destruction and Bosses'Rise bosses. Report anything odd and it gets a hotfix.

## Release checklist
0. **Before releasing 0.5.0:** the 6 Every Compat willow chests at spawn (x -312, y 85-86, z -3207 to -3211) must be emptied. 0.5.0 drops Every Compat's Quark copies, so those chests and everything in them disappear. They are the only removed-mod blocks in the world (full scan of the latest backup).
1. Check `version` in `pack.toml` and the version line in `config/fancymenu/customization/strata_title_screen.txt` (both 0.5.0).
2. `python -I tools/curseforge_ids.py` (re-adds CurseForge IDs after mod updates; fix any "no longer used" line in
   `tools/curseforge-manual.json`), `packwiz refresh`, commit, `git push` (master, and sync `next-update`). Check no stray files sit under the server's `kubejs/data`: KubeJS refuses to start on an uppercase file name there.
3. `packwiz mr export -o build/Strata-<version>.mrpack`; `gh release create v<version>` with the notes below.
   The CurseForge Action (`.github/workflows/curseforge.yml`) then builds `Strata-<version>-curseforge.zip`, attaches
   it to the release and, when the repo variable `CURSEFORGE_UPLOAD` is `true`, uploads it to CurseForge with the
   release notes as the changelog (CurseForge reviews it before it goes public). One-time setup by the repo owner: secret
   `CURSEFORGE_TOKEN`, variables `CURSEFORGE_PROJECT_ID` and `CURSEFORGE_UPLOAD`; leave the upload off until
   Drive-By-Wire is on CurseForge's approved list (requested), or CurseForge rejects the file. To upload a
   release that's already out: Actions → CurseForge → Run workflow with its tag.
4. Wait about 5 minutes for GitHub's raw-file cache, then restart the server (Quarry restart, or `docker compose restart`
   in `/opt/minecraft/strata`). Check the log for `Loaded N/N KubeJS server scripts ... 0 errors`.
5. Tell the group to import the new `.mrpack`.

Note: `config/DistantHorizons.toml` and `config/cameraoverhaul.toml` are `preserve = true`, so players who already have
them keep their own copy. Changes there only reach new installs.
