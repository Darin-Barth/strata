# Queued for the next update

Changes committed on master since the last release (**v0.3.0**, Oct 26, 2026) that haven't been released yet. Policy: changes ship together in one update (merge to `master` + new `.mrpack` release + server restart); only a critical hotfix goes out on its own. Queued work can be backed up to the GitHub branch `next-update` (`git push origin master:refs/heads/next-update`); the server only follows `master`.

## Changes
- **New: The Abyssal Plain**, an underwater dimension with no surface (`docs/abyssal-plain-design.md`). Dark prismarine portal lit with the **Tidecaller** (Conduit + 2 Deep Seas ballast tanks + prismarine crystals); you arrive in a sealed **Lifepod**. Shelves, the plain, vent fields, a bioluminescent garden and deep trenches; the sea floods anything you break; no Conduit power or sponges there; bases are sealed rooms you pump dry and give air with Create: Deep Seas. Creatures from Hybrid Aquatic, Alex's Caves Continued (abyss only, its Overworld caves off), Naturalist, Upgrade Aquatic and Alex's Mobs; ruins from Sunken Spires (now only here) and Moog's Ocean Structures. Boss ladder Karkinos → Hullbreaker → the **Leviathan Lure** → Cataclysm's Leviathan. Abyssal Pearls (gate material). New mods: Hybrid Aquatic + Hybrid API, Alex's Caves Continued, Scannable, Field Guide (+ Immersive Overlays, Item Descriptions), Sunken Spires, MOS, Glow Sticks. Also: English names for all custom biomes (the Pokémon world's showed raw keys). Pregenerate it on the server after the update. Not yet tested with a client.
- **New: skill trees** (Pufferfish's Skills 0.19.2 beta + Attributes + Unofficial Additions; Lopez's request, Darin approved Oct 26). Open them with **Ctrl+K** (its default K is the Iris shader toggle in our keymap; set in `config/defaultoptions/keybindings.txt`, so existing players get it after Reset All or rebind it themselves). Trees: **Combat** and **Mining** (Default Skill Trees; Combat capped at 40 levels in `kubejs/data/puffish_skills/.../combat/experience.json`, otherwise it never ends: a full tree is +18 hearts, +75% damage, +50% speed), **Fishing** (our own, `kubejs/data/strata/puffish_skills`: luck, breath, swim speed, a couple of hearts), and Iron's **Magic I/II + Primary/Secondary School** (spell casting gives XP; you pick one school per tier). Test server Oct 26: all three tree packs load (`Data pack ... loaded successfully`); not yet checked in-game (open the screen, earn XP from kills/mining/fishing/casting, unlock a node).
- **The Pokémon world is now the Kakuto Region** (title banner and quest book; Darin, Oct 26). Same dimension, same portal.
- **Every portal has its own look and sound:** Unown Drift (Kakuto: gold light, drifting Unown, bell chimes and wind), Dead Signal (the Hollow: grey static that freezes, whispers, creaking, long silences), marine snow (Abyssal Plain: deep water, falling flecks, deep-sea calls). New Tidecaller art (a drowned compass). Hollow portals lit before the update may need relighting (break one frame block and light it again).
- **The Hollow, fixed:** the Ravenous and its Screechers now actually appear (rarely); the Corrupted Champion can be summoned (its blood vial fills from the Hollow's corrupted villagers and illagers); the 40% damage cap also covers a Weeping Angel's neck snap and the Gate Guardian's dying smite; Hollow Embers now turn up in Grim & Bleak's ruined-portal chests.
- **Removed, to keep teleporting and flight earned** (Darin, Oct 26): Iron's Spells **Recall** (Portal and Pocket Dimension stay), all **Draconic Evolution dislocators** (no recipe), and the **Helium Flamingo**, **Wind Staff** and Forsaken Relics' **Linking Book** no longer drop from loot. Copies you already have keep working.

## Release checklist
1. Bump `version` in `pack.toml` and the version line in `config/fancymenu/customization/strata_title_screen.txt`.
2. `packwiz refresh`, commit, `git push` (master, and sync `next-update`). Check no stray files sit under the server's `kubejs/data`: KubeJS refuses to start on an uppercase file name there (Oct 26 outage).
3. `packwiz mr export -o build/Strata-<version>.mrpack`; `gh release create v<version>` with the notes below.
4. Wait about 5 minutes for GitHub's raw-file cache, then restart the server (Quarry restart, or `docker compose restart`
   in `/opt/minecraft/strata`). Check the log for `Loaded N/N KubeJS server scripts ... 0 errors`.
5. Tell the group to import the new `.mrpack`.

Note: `config/DistantHorizons.toml` and `config/cameraoverhaul.toml` are `preserve = true`, so players who already have
them keep their own copy. Changes there only reach new installs.
